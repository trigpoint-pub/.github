## Read → try → use / 閱讀 → 試用 → 應用

| 入口 / Entry | 用途 / Purpose |
|---|---|
| [trigpoint.pub](https://trigpoint.pub/) | 最新文章、方法與修正。Current articles, methods and corrections. |
| [Reading notes / 閱讀筆記](https://github.com/trigpoint-pub/trigpoint) | 多語文章快照，方便閱讀、引用及核對版本。Multilingual snapshots for reading and citation. |
| [Agent skills / 技能合集](https://github.com/trigpoint-pub/agent-skills#choose-by-task) | 按任務選擇示例、教學及可獨立安裝的 skill。Task-based examples, tutorials and independently installable skills. |

Skills 由 Ansel 維護，現為 experimental／trial prereleases；各版本列明已驗及未驗範圍。

Skills are maintained by Ansel. They are experimental or trial prereleases, with explicit validation limits for each version.
